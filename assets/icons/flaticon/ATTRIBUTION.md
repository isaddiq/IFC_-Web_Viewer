# Flaticon icon attribution

The colored UI icons in this folder are local PNG copies sourced from Flaticon
free icon pages. Flaticon free assets require attribution in the final project.
See https://www.flaticon.com/license/license.pdf for the current license terms.

The app maps these source files to every `Icons.*` item in
`assets/js/ui/icons.jsx`; several similar actions intentionally share one icon.
Some grayscale source PNGs were locally tinted to keep the app icon set
consistently colored.
